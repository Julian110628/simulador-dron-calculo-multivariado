# Simulador de trayectoria de un dron

Versión optimizada con animación Plotly ejecutada en el navegador.

## Características
- Coordenadas A y B editables.
- Actualización automática de métricas y tablas.
- Vista 2D.
- Animación 3D fluida del trazado.
- Click en leyenda para ocultar/mostrar trayectorias.
- Doble click para aislar una trayectoria.
- Campo vectorial opcional desde la leyenda.
- Modelo matemático y RK4.

## Ejecutar

```bash
pip install -r requirements.txt
streamlit run app.py
```
